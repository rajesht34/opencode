# Local OpenCode Install Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install the pinned toolchain and workspace dependencies for this `dev` checkout so the OpenCode V2 CLI answers `--version` and `debug paths`, and `bun dev .` opens the terminal UI.

**Architecture:** Match the CI install in `.github/actions/setup-bun/action.yml`: Node 24 on `PATH` for native install scripts, Bun taken from the root `packageManager` field, then `bun install --frozen-lockfile` at the repository root. Prove the install with the source CLI entry `packages/cli/src/index.ts`. A source run does not inject `OPENCODE_VERSION`, so `packages/cli/src/version.ts` reports `local`.

**Tech Stack:** Windows PowerShell, Node.js 24.22.2 (x64 zip), Bun 1.4.4 (official Windows installer), this repo's Bun workspaces (`package.json` workspaces: `packages/*`, `packages/plugins/*`, `services/*`, `packages/stats/*`).

## Global Constraints

- Root `package.json` field `packageManager` is `bun@1.4.4`.
- `CONTRIBUTING.md` says: "OpenCode requires Bun 1.3 or newer." Install `1.4.4`, which satisfies that floor and matches `packageManager`.
- `.github/actions/setup-bun/action.yml` sets Node with `node-version: "24"` because "node-gyp@latest (invoked via bunx for native install scripts) requires Node >=22".
- CI install line is `bun install --frozen-lockfile`.
- Root script `test` is `echo 'do not run tests from root' && exit 1`. This plan does not run the root `test` script.
- `CONTRIBUTING.md` dev loop is `bun install` then `bun dev [directory]`. `bun dev` runs the V2 CLI and TUI. Pass `.` to open this repository.
- Default branch is `dev`. Work in `D:\Docs\Rajesh Docs\Code\opencode` on branch `dev`.
- Bun's Windows installer requires Windows 10 version 1809 or later.
- This plan does not run `bun run generate`, does not edit generated client files, and does not add `.changeset` files.
- Do not commit `node_modules` or a rewritten `bun.lock`. These tasks install tools outside the repo and dependencies that are gitignored.

- [ ] **Step 3: Install Node 24.22.2 for the current user**

This is the latest Node 24 build published at `https://nodejs.org/dist/latest-v24.x/` (28 Oct 2026). Use the x64 zip. Do not use the `OpenJS.NodeJS.LTS` winget id; in late 2026 that id can move off Node 24.

```powershell
$version = "24.22.2"
$destParent = Join-Path $env:LOCALAPPDATA "Programs"
$nodeHome = Join-Path $destParent "node-v$version-win-x64"
$zip = Join-Path $env:TEMP "node-v$version-win-x64.zip"
New-Item -ItemType Directory -Force -Path $destParent | Out-Null
Invoke-WebRequest -Uri "https://nodejs.org/dist/v$version/node-v$version-win-x64.zip" -OutFile $zip
Expand-Archive -Path $zip -DestinationPath $destParent -Force
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
$parts = @($userPath -split ";" | Where-Object { $_ -and ($_ -ne $nodeHome) })
[Environment]::SetEnvironmentVariable("Path", (($parts + $nodeHome) -join ";"), "User")
$env:Path = "$nodeHome;" + $env:Path
& "$nodeHome\node.exe" --version
```

Expected last line: `v24.22.2`.

- [ ] **Step 4: Run the test to verify it passes**

Run the Step 1 script again in the same PowerShell window.

Expected: `PASS node v24.22.2`

- [ ] **Step 5: Confirm git is unchanged**

```powershell

git diff -- bun.lock
```

Expected: `git diff -- bun.lock` prints nothing. `git status --short` does not list Node install files (they live under `%LOCALAPPDATA%`, outside the repo). Do not create a commit.
